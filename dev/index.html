HTTP.jl

HTTP.jl is an HTTP client and server library for Julia. It speaks HTTP/1.1 and HTTP/2, streams request and response bodies, and supports WebSockets and server-sent events. Reseau provides the TCP, DNS, and TLS layers.

Quick Start

Start a server, send it a request, and read the response body:

using HTTP

server = HTTP.serve!("127.0.0.1", 0) do req
    return HTTP.Response(200; body = "hello from HTTP.jl")
end

resp = HTTP.get("http://127.0.0.1:$(HTTP.port(server))/hello")
HTTP.forceclose(server)
String(resp.body)  # "hello from HTTP.jl"

Port 0 asks the operating system for a free port; HTTP.port(server) returns the one it chose.
